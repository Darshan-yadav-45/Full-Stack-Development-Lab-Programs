
# Full Stack Development (FSD) Lab Programs

Welcome to my Full Stack Development (FSD) Lab Programs repository. This repository contains practical exercises and programs developed as part of my MCA Full Stack Development laboratory work.

The programs cover frontend development, JavaScript programming, JSON data handling, and PHP-based web applications.

## About the Repository

The main objective of this repository is to understand and implement fundamental Full Stack Development concepts through practical coding exercises.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- JSON
- Visual Studio Code
- XAMPP

## Programs List

| No. | Program Name | Technologies |

## Program Details

### 1. Dynamic To-Do List

A dynamic task management application that allows users to:

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Add tasks using the Enter key.

**JavaScript Concepts:**
- Arrow Functions
- Template Literals
- DOM Manipulation
- Event Listeners
- Event Handling

### 2. Read JSON Data and Render It in a Table

A JavaScript program that reads sample JSON data and dynamically displays student or user information in an HTML table.

**Concepts Used:**
- JSON Data
- JavaScript Objects and Arrays
- `Object.keys()`
- `Object.values()`
- DOM Manipulation
- Dynamic HTML Table Creation

### 3. Student Management System Using JSON

A PHP-based student management program that demonstrates basic student record operations using JSON.

**Features:**
- Create student records.
- Convert PHP arrays into JSON.
- Decode JSON data.
- Validate JSON data.
- Display student details.
- Search students by ID.
- Update student marks.
- Delete student records.
- Display final JSON output.

**PHP Concepts:**
- PHP Arrays
- `json_encode()`
- `json_decode()`
- `json_last_error()`
- `foreach` Loop
- Conditional Statements
- Functions

## How to Run the Programs

### HTML, CSS and JavaScript Programs

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required program folder.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. View the output in your web browser.

### PHP Programs Using XAMPP

1. Install XAMPP.
2. Copy the PHP project folder into:

   `C:\xampp\htdocs\`

3. Open XAMPP Control Panel.
4. Start Apache.
5. Open your browser.
6. Enter the following URL:

   `http://localhost/Student-Management-System/`
